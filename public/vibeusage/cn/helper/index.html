vibeUsage Mac 助手

让本机 Claude 账号的额度读数保持更新。安装助手一次，再返回 vibeUsage 确认启用。

下载 Mac 助手

版本 1.0.0 · macOS 13 或更新版本 · Apple 芯片与 Intel

安装前

请先在这台 Mac 安装带有“主动刷新设置”入口的 vibeUsage 版本，并安装官方 Claude Code，登录你想查看额度的 Claude 订阅账号。

Claude Code 安装说明

三步完成安装

  1. 下载并打开
    打开 ZIP 文件，再双击里面的 vibeUsage 助手。
  2. 按屏幕指引安装
    助手会引导你完成这台 Mac 上的安装。
  3. 返回 vibeUsage
    在 App 中确认启用主动刷新。如果 macOS 要求文件夹访问权限，选择提示中的助手文件夹。首次额度读取成功后，设置就完成了。

设置完成后，可以删除下载的安装副本。vibeUsage 的手动和自动刷新会使用已安装的助手。

沿用 Claude 的现有登录

不需要向助手复制密码、令牌或 API Key。助手沿用官方 Claude Code 的登录来刷新额度，不会发起对话。

停用或卸载助手

在 vibeUsage 的 Claude 账号设置中停用主动刷新，即可恢复读取缓存。要从这台 Mac 移除助手，重新打开安装器并选择卸载。你的 Claude Code 登录和配置会保留。
