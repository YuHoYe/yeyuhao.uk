vibeUsage Mac 助手

在 vibeUsage 中点「启用主动刷新」即可直接下载助手，打开一次就能完成设置。这里也提供备用下载。

下载 Mac 助手

版本 1.0.1 · macOS 13 或更新版本 · Apple 芯片与 Intel

安装前

请先在这台 Mac 安装带有“主动刷新设置”入口的 vibeUsage 版本，并安装官方 Claude Code，登录你想查看额度的 Claude 订阅账号。

Claude Code 安装说明

从 vibeUsage 开始

  1. 在 App 中下载
    在本机 Claude 账号的主动刷新设置中点「启用主动刷新」，浏览器会直接下载 ZIP。若已从本页下载，继续下一步即可。
  2. 打开助手一次
    打开 ZIP 文件，再双击里面的 vibeUsage 助手。如果 macOS 提示是否打开，请确认。助手会自动安装并返回 vibeUsage；找不到 Claude Code 或尚未登录时，才会显示设置供你处理。
  3. 取得首次读数
    从 vibeUsage 发起的安装会自动连接。从本页直接下载的用户，需要在 App 中确认启用主动刷新。首次额度读取成功后，设置就完成了。

设置完成后，可以删除下载的安装副本。vibeUsage 的手动和自动刷新会使用已安装的助手。

沿用 Claude 的现有登录

不需要向助手复制密码、令牌或 API Key。助手沿用官方 Claude Code 的登录来刷新额度，不会发起对话。

停用或卸载助手

在 vibeUsage 的 Claude 账号设置中停用主动刷新，即可恢复读取缓存。要从这台 Mac 移除助手，打开下载的助手，切回助手窗口并选择「卸载助手」。你的 Claude Code 登录和配置会保留。
