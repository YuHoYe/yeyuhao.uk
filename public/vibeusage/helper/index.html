vibeUsage Helper for Mac

Keep the quota for your local Claude account up to date. Install the Helper once, then return to vibeUsage to enable refreshing.

Download for Mac

Version 1.0.0 · macOS 13 or later · Apple silicon and Intel

Before you begin

Install a version of vibeUsage with Active Refresh settings on this Mac. Claude Code must also be installed and signed in with the Claude subscription you want to monitor.

Claude Code installation guide

Install in three steps

  1. Download and open
    Open the ZIP file, then double-click the vibeUsage Helper inside.
  2. Follow the installation steps
    The Helper guides you through installation on this Mac.
  3. Return to vibeUsage
    Confirm enabling active refresh in the app. If macOS asks for folder access, choose the Helper folder shown in the prompt. A successful first reading confirms setup.

Once setup is complete, you can delete the downloaded installation copy. vibeUsage's manual and automatic refresh will use the installed Helper.

Your existing sign-in stays with Claude

You do not need to copy a password, token or API key into the Helper. It uses Claude Code's existing sign-in to refresh your quota and does not submit a chat prompt.

Turn off or remove the Helper

To return to cached readings, turn off active refresh in the Claude account's settings in vibeUsage. To remove the Helper from this Mac, reopen the installer and choose Uninstall. Your Claude Code sign-in and configuration stay in place.
