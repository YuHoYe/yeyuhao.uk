vibeUsage Helper for Mac

In vibeUsage, choose Enable Active Refresh to download the Helper directly. Open it once to finish setup. You can also download it here.

Download for Mac

Version 1.0.1 · macOS 13 or later · Apple silicon and Intel

Before you begin

Install a version of vibeUsage with Active Refresh settings on this Mac. Claude Code must also be installed and signed in with the Claude subscription you want to monitor.

Claude Code installation guide

Start in vibeUsage

  1. Download from the app
    In your local Claude account's Active Refresh settings, choose Enable Active Refresh. Your browser downloads the ZIP directly. If you downloaded from this page, continue with the next step.
  2. Open the Helper once
    Open the ZIP, then double-click the vibeUsage Helper inside. Confirm opening if macOS asks. The Helper installs automatically and returns to vibeUsage. If Claude Code cannot be found or is not signed in, the Helper shows settings to resolve it.
  3. Get your first reading
    Setup started from vibeUsage connects automatically. If you started from this page, confirm enabling active refresh in the app. A successful first reading confirms setup.

Once setup is complete, you can delete the downloaded installation copy. vibeUsage's manual and automatic refresh will use the installed Helper.

Your existing sign-in stays with Claude

You do not need to copy a password, token or API key into the Helper. It uses Claude Code's existing sign-in to refresh your quota and does not submit a chat prompt.

Turn off or remove the Helper

To return to cached readings, turn off active refresh in the Claude account's settings in vibeUsage. To remove the Helper from this Mac, open the downloaded Helper, switch back to its window and choose Uninstall helper. Your Claude Code sign-in and configuration stay in place.
